# usagiengine.com

Website for Usagi Engine. Static site generated by `main.ts`. Requires Just,
Deno, Ruby, the `bunny` CLI for developing and deploying.

Reads various engine files, like ../README.md and ../CHANGELOG.md (among
others), and generates HTML in the `_build` directory.

## Developing

Boot up the dev server at http://localhost:8008: `just dev`

This generates the site and starts a server to view it.

Changing the files in `../` requires generating the site with `just build`.

## Deploying

Deploy the site with `just deploy`. This needs to happen manually.

## Redirects

Redirects for the deployed site are managed via Bunny.net's CDN Edge Rules at:
https://dash.bunny.net/cdn/6679857/edge-rules

## Install scripts

`install.sh` and `install.ps1` are served as `text/plain` from `/install.sh` and
`/install.ps1`. Both resolve the latest GitHub release, verify its SHA-256, and
install to `~/.usagi/bin/usagi` (or `%USERPROFILE%\.usagi\bin\usagi.exe` on
Windows).

```
curl -fsSL https://usagiengine.com/install.sh | sh
irm https://usagiengine.com/install.ps1 | iex
```

Override the install dir with `USAGI_INSTALL` / `$env:UsagiInstall`.
